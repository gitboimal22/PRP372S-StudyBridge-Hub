## About the Project

StudyBridge Hub is a web-based learning support idea for the iGugulam Community Programme. The platform is designed to help learners access educational resources, tutorials, revision support, and guidance in a more structured way. It also gives parents or guardians a clearer view of how their child can receive academic support.

## Project Purpose

The purpose of this project is to use technology to make educational support easier to access. The platform focuses on learners who may need extra academic help and parents who want a reliable way to understand what support is available.

## Main Users

- **Learners** who need academic resources, tutorials, and revision guidance.
- **Parents or guardians** who want to support their child academically.
- **Programme facilitators or educators** who may use the platform to organise learning support.

## User Stories

| User | User Story | Value |
|---|---|---|
| Learner | As a learner, I want access to educational support so that I can improve my academic performance. | Helps learners find resources and guidance. |
| Parent / Guardian | As a parent or guardian, I want a reliable support platform so that I can understand how my child can get academic help. | Builds trust and makes support easier to follow. |
| Facilitator | As a facilitator, I want organised learning resources so that I can guide learners more effectively. | Makes academic support easier to manage. |
